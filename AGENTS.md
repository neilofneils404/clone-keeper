# Clone Keeper

An Omarchy plugin and bundled Python CLI for maintaining customized built-in
plugins. The first alpha captures trustworthy baselines and exports reviewable
three-way merge candidates. Applying changes and rollback are future work.

## Development

- Work in this repository. Treat `/usr/share/omarchy` and installed user plugins
  as read-only reference material during development.
- Python runtime dependencies are the standard library and the `git` executable.
- Use `python -m unittest discover -s tests -v` for the integration suite.
- Run `scripts/check-ui.sh` when changing the plugin UI. It chooses Qt 6's
  linter, maps Quickshell imports, and runs Omarchy's manifest validator.
- Keep CLI stdout machine-readable for `--json`; report errors on stderr.
- A baseline must be captured from an unchanged clone or explicitly supplied by
  its owner. Never infer historical ancestry from today's upstream source.
- Preserve clone identity, binary files, executable bits, and deletion conflicts.
- Status and previews must not write to plugin directories or execute plugin code.
- Do not commit generated bytecode, user snapshots, exports, or machine settings.

## Release direction

See `docs/ROADMAP.md`. This alpha is not yet a marketplace release. Publication
requires a tested apply/undo design, real desktop verification, and release assets.
